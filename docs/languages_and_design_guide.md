# دليل لغات البرمجة وملفات تصميم الموقع (Languages & Design Files Guide)

هذا المستند يوضح **جميع لغات البرمجة المستخدمة** في هذا المشروع، وأماكن ملفاتها الدقيقة، بما فيها ملفات تصميم وبرمجة الموقع.

---

## 1. لغة Python 🐍

**الاستخدام:** لغة الأساس في المشروع كاملاً — الذكاء الاصطناعي، السيرفر، معالجة البيانات، والاختبارات.

| الملف / المجلد | الوظيفة |
|---|---|
| `src/feature_extractor.py` | مستخرج الخصائص — قلب المشروع |
| `src/paths.py` | إدارة مسارات الملفات بشكل مطلق |
| `src/__init__.py` | تعريف حزمة Python |
| `src/api/__init__.py` | تعريف حزمة الـ API |
| `src/api/main.py` | سيرفر FastAPI — الـ Backend الرئيسي |
| `scripts/01_build_dataset.py` | بناء مجموعة البيانات من الروابط الخام |
| `scripts/02_verify_dataset.py` | التحقق من صحة البيانات المعالجة |
| `scripts/03_eda.py` | التحليل الاستكشافي وإنشاء الرسوم البيانية |
| `scripts/04_train_model.py` | تدريب نماذج الذكاء الاصطناعي واختيار الأفضل |
| `tests/test_feature_extractor.py` | 51 اختباراً لخصائص استخراج الروابط |
| `tests/test_api.py` | 46 اختباراً للـ API والأمان |
| `tests/test_integration.py` | 13 اختباراً للتكامل بين التدريب والتشغيل |
| `tests/test_external.py` | اختبارات على روابط حية من PhishTank |
| `run_api.py` | تشغيل السيرفر بأمر واحد |

**إجمالي ملفات Python: 14 ملف**

## 2. لغة HTML5 🌐

**الاستخدام:** هيكل صفحة الموقع والواجهة المعروضة في المتصفح.

| الملف | الوظيفة |
|---|---|
| `src/api/static/index.html` | الملف الوحيد للواجهة — يحتوي كل شيء (HTML + CSS + JS في ملف واحد) |

**المحتوى داخل `index.html`:**
- `<head>` — إعدادات الصفحة والعنوان والخطوط
- `<header>` — رأس الصفحة مع الأيقونة والعنوان
- `<main>` — نموذج إدخال الرابط وقسم عرض النتائج
- `<footer>` — تذييل الصفحة

---

## 3. لغة CSS3 🎨 (تصميم الموقع)

**الاستخدام:** كل تصميم الموقع البصري — الألوان، الخطوط، الأحجام، التحريكات، والتخطيط.

**مكان ملفات التصميم:**
> ⚠️ التصميم مدمج داخل ملف واحد: `src/api/static/index.html`
> داخله وسم `<style>` يحتوي على كامل كود CSS.

**أبرز عناصر التصميم المستخدمة في `<style>`:**

| عنصر التصميم | الوظيفة |
|---|---|
| `CSS Variables (--primary, --danger...)` | نظام ألوان موحد قابل للتعديل |
| `Google Fonts (Cairo)` | خط عربي احترافي |
| `Flexbox & Grid` | تخطيط الأعمدة والصفوف |
| `border-radius, box-shadow` | الزوايا المنحنية والظلال |
| `@keyframes` | تحريكات الظهور والبناء التدريجي |
| `transition` | تأثيرات الانتقال عند التحويم |
| `direction: rtl` | دعم الكتابة من اليمين لليسار (عربي) |
| `@media queries` | استجابة الموقع لأحجام الشاشات المختلفة |

## 4. لغة JavaScript 🟨

**الاستخدام:** التفاعلية في المتصفح — إرسال الطلبات وتحديث الواجهة وعرض النتائج.

**مكان الملفات:**
> مدمجة داخل `src/api/static/index.html` داخل وسم `<script>`.

**الوظائف الرئيسية المكتوبة بـ JavaScript:**

| الدالة / الوظيفة | ما تفعله |
|---|---|
| `checkUrl()` | ترسل الرابط للـ API وتستقبل النتيجة |
| `fetch('/api/v1/predict', {...})` | طلب HTTP/POST للـ Backend |
| `renderResult(data)` | تحديث واجهة الموقع بالنتيجة والألوان |
| `renderFeatures(features)` | عرض الخصائص التفسيرية الثلاث الأهم |
| `animateBar(percent)` | تحريك شريط الاحتمالية من 0% إلى النسبة |
| `Enter keydown listener` | السماح بالفحص عبر مفتاح Enter |

## 📁 ملخص مواقع ملفات تصميم الموقع (تصميم الـ Frontend)

```
src/api/static/index.html       ← الملف الوحيد الذي يحتوي:
│
├── <style>...</style>          ← كود CSS3 الكامل (التصميم والألوان والتحريكات)
├── <body>...</body>            ← كود HTML5 الكامل (الهيكل والعناصر)
└── <script>...</script>        ← كود JavaScript الكامل (التفاعلية)
```

> **سبب دمج الملفات الثلاثة في ملف واحد:** تبسيط النشر وتسريع التحميل. في مشاريع أكبر يُفصل كل منها في ملف مستقل.
