# الميزات الشبكية (Network Features) - الدليل الشامل

## نظرة عامة

تم إضافة **5 ميزات شبكية جديدة** إلى نظام كشف التصيد، مما يرفع إجمالي الميزات من **37 إلى 42 ميزة**:

### الميزات الجديدة:
1. **domain_age_days** - عمر النطاق بالأيام (WHOIS)
2. **ssl_valid** - صلاحية شهادة SSL/TLS
3. **ssl_days_left** - الأيام المتبقية لانتهاء الشهادة
4. **ssl_self_signed** - هل الشهادة موقعة ذاتيًا؟
5. **ssl_wildcard** - هل الشهادة تستخدم بدل (*)?

---

## ⚙️ كيفية العمل: الاكتشاف التلقائي الذكي

النظام يدعم **3 أوضاع** لاستخدام الميزات الشبكية:

### 1. **الوضع التلقائي** `network="auto"` (الافتراضي)
```python
features = extract_features("https://example.com", network="auto")
```
- **يكتشف الإنترنت تلقائيًا** عند أول استدعاء
- **إذا كان الإنترنت متاحًا** → يستخدم WHOIS و SSL
- **إذا كان الإنترنت معطلاً** → يستخدم قيمًا افتراضية آمنة (-1/0)
- **الفحص يحدث مرة واحدة فقط** لكل جلسة لتجنب التأخير

### 2. **التفعيل الإجباري** `network=True`
```python
features = extract_features("https://example.com", network=True)
```
- يحاول الاتصال بالشبكة حتى لو كان الإنترنت بطيئًا أو معطلاً
- **تحذير**: قد يستغرق 5-10 ثوانٍ لكل رابط!

### 3. **التعطيل الإجباري** `network=False`
```python
features = extract_features("https://example.com", network=False)
```
- لا يتصل بالشبكة إطلاقًا (سريع وآمن)
- جميع الميزات الشبكية تأخذ قيمها الافتراضية
