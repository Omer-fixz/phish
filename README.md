# نظام كشف روابط التصيد الاحتيالي

مشروع تخرج — كشف روابط التصيد بتحليل نص الرابط فقط، دون أي اتصال بالموقع المفحوص.

## النتائج

| المؤشر | القيمة |
|-|-|
| النموذج | XGBoost (depth=6, lr=0.1) |
| Accuracy (تقسيم حسب النطاق) | 0.9029 |
| Precision / Recall / F1 | 0.8796 / 0.9222 / 0.9004 |
| ROC-AUC | 0.9725 |
| عتبة القرار | 0.38 (مختارة من مجموعة التحقق) |
| **الكشف على تصيد حديث من PhishTank** | **0.9357** |
| الكشف على نطاقات لم يرها النموذج | 0.9246 |
| الكشف على OpenPhish (مصدر مستقل) | 0.9467 |

الدقة بتقسيم عشوائي تصل إلى 0.9420، وهو **رقم متضخّم لا يُعتمد**: 69.6% من الروابط تقع في نطاقات مكررة، فالتقسيم العشوائي يضع النطاق نفسه في التدريب والاختبار.

### البيانات الخارجية

```bash

curl -sL -o data/tranco_top1m.csv.zip https://tranco-list.eu/top-1m.csv.zip
curl -sL -o data/phishtank.csv.gz http://data.phishtank.com/data/online-valid.csv.gz
curl -sL -A "Mozilla/5.0" -o data/openphish.txt https://openphish.com/feed.txt
```

ثم فُكّ ضغط ملف تارانكو داخل `data/` ليصبح `data/top-1m.csv`.

كما يلزم ملف المصدر الأصلي `Final_Phishing_Dataset_96k.csv` في جذر المشروع.

## قرارات منهجية

1. **التقسيم حسب النطاق** (`GroupShuffleSplit`) لا عشوائياً، ويُتحقَّق برمجياً من عدم تداخل النطاقات بين المجموعات الثلاث.
2. **مستخرج خصائص واحد** يُستورد في التدريب والتشغيل معاً. اختلافه بين المرحلتين أشهر عطل في هذا النوع من المشاريع، و`test_integration.py` يمنعه.
3. **العتبة تُختار من مجموعة التحقق** بقاعدة: أعلى استدعاء بشرط ألا تتجاوز الإنذارات الكاذبة 10%، وتُحفظ داخل النموذج ليقرأها التطبيق.
4. **الخصائص الميتة تُحذف**: `has_ip_address` و`is_https` قيمتهما صفر في كل الصفوف.
5. **لا يُفتح الرابط إطلاقاً** — لا WHOIS ولا تنزيل صفحة ولا تتبع إعادة توجيه.

## حدود النظام

1. الروابط في المصدر الأصلي بلا بروتوكول، لذلك `is_https` ثابتة صفراً وحُذفت.
2. لا يوجد أي رابط قائم على عنوان IP، لذلك `has_ip_address` ثابتة صفراً وحُذفت.
3. الروابط الشرعية في المصدر أقصر بكثير من الاحتيالية، وهو انحياز مصدر يجعل `url_length` أقوى مما تستحق.
4. أُضيف 5,000 نطاق شرعي مجرد من قائمة تارانكو لسد فجوة: النطاقات بلا مسار كانت 0.35% فقط من الشرعي مقابل 8.60% من التصيد، فكان النموذج يصنّف `google.com` تصيداً.
5. **نسبة الإنذارات الكاذبة المعتمدة هي 11.5%** المقاسة على مجموعة الاختبار الأصلية. الرقم المنخفض في الاختبار الخارجي (0.13%) متفائل لأن جانبه الشرعي نطاقات مجردة سهلة.
6. **حد نظري**: الروابط الفائتة غالباً مواقع شرعية مخترقة تستضيف صفحة تصيد. نصّ الرابط فيها خالٍ من أي دليل، ولا يمكن لأي نموذج معجمي كشفها.
